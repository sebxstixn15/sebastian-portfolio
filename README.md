# Sebastian Lampl portfolio

A zero-build static portfolio. Open `index.html` locally or deploy the folder to any static host.

## Deployment

1. Create a new repository for the portfolio, then add the files in this folder.
2. Choose a static host (GitHub Pages, Netlify, or Vercel) and set the publish directory to this folder's root.
3. Connect the resulting public URL to the GitHub profile README.

The page deliberately directs contact through GitHub and contains no private address or phone number.
